# インターバル・バブルカメラ

個人所有のAndroid 16端末専用に、1〜60秒間隔の写真を自動撮影するアプリです。撮影開始後はアプリがバブルになり、他のアプリを使っている間や画面ロック中もインターバル撮影を継続します。画面表示は日本語のみです。

## 主な機能

- 1〜60秒の撮影間隔（1秒刻み）
- 背面・前面カメラの選択
- ステータスバー領域と左右半分の画面外まで移動できるフローティングバブル
- 画面ロック中もCPUを起動状態に保って撮影を継続
- バブルとランチャーアイコンを7色から選択（ブラックを含み、選択を端末内に保存）
- バブルをタップしてアプリへ復帰
- 常駐通知から撮影停止
- 撮影枚数と最終保存ファイル名の表示
- 写真を `Pictures/IntervalBubbleCamera` に保存
- 同梱画像を切らずに没入型の全画面で表示（画面タップまたは戻る操作で終了）
- 外部送信なし（インターネット権限も未使用）

## 動作条件

- Android 16（API 36）のみ
- 個人所有端末での利用を前提
- カメラを搭載した実機
- Android Studio Meerkat 2024.3.1以降を推奨
- JDK 17
- Android SDK 36

## ビルドとインストール

1. Android Studioでこのリポジトリを開きます。
2. Android SDK 36が未導入なら、SDK Managerから追加します。
3. USBデバッグを有効にしたAndroid実機を接続します。
4. `app` 構成を選び、Runを押します。

コマンドラインの場合:

```bash
./gradlew testDebugUnitTest assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

## 使い方

1. 撮影間隔、カメラ、アイコン色を選びます。
2. 「開始してバブル化」を押します。
3. 初回だけ、カメラ・通知・他のアプリ上への表示を許可します。
4. カメラ準備後にアプリが背面へ移動し、バブルが表示されます。
5. 必要なら、撮影中であることを確認してから画面をロックします。
6. バブルをドラッグして移動、タップしてアプリへ戻れます。
7. 停止はアプリ画面または常駐通知の「停止」から行います。
8. 「画像を全画面表示」を押すと同梱画像が開きます。画像をタップするか戻る操作で閉じます。

## Androidの制約と注意点

- Androidのプライバシー仕様により、撮影中はカメラ使用インジケーターと常駐通知が表示されます。非表示にはできません。
- 7色設定で変わるのはアプリのランチャーアイコンとバブルだけです。ブラックを選んでも、Android右上の緑色カメラ使用表示の色は変更されません。
- Android 16のバックグラウンドカメラ制約に対応するため、撮影サービスは必ず画面ロック前かつアプリ画面が前面にある状態で開始します。その後はカメラ用フォアグラウンドサービスとして継続します。
- 画面ロック中は部分Wake Lockを撮影ごとに更新します。停止時や異常終了時には必ず解放します。
- 1秒間隔は端末の発熱、電池消費、保存容量への負荷が大きくなります。
- 指定値は撮影開始時刻の目標間隔です。カメラの処理が指定間隔より長い場合は、写真を重複して処理せず、前の保存完了後すぐ次を撮影します。
- 極端な省電力モードやメーカー独自のバックグラウンド制限により、ロック中の間隔が遅れたりサービスが停止したりすることがあります。
- カメラを利用する別アプリとは同時に撮影できません。

## 実装概要

- Kotlin / Android Views
- CameraX `ImageCapture`
- `LifecycleService` + `foregroundServiceType="camera"`
- `PARTIAL_WAKE_LOCK`（10分の安全タイムアウトを各撮影前に更新）
- `TYPE_APPLICATION_OVERLAY` のフローティングバブル
- MediaStore / scoped storage
- Min/Target/Max SDK 36、CameraX 1.6.1

## プライバシー

写真は端末の共有Pictures領域だけに保存します。アプリはインターネット権限を宣言せず、写真・利用情報を外部へ送信しません。撮影は端末所有者がアプリ画面から明示的に開始した場合に限られ、常駐通知とバブルから状態を確認・停止できます。
