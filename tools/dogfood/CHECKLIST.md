# 設定の値の確かめ方（ドッグフーディング）

設定の値（撮り方ごとの撮影間隔・変化の大きさ・変化の広さ）が、実際の場面で「残すべき写真を残し、余計な写真を
残さない」かを確かめる手順です。

## 準備

1. CI で作ったアプリ（デバッグ APK）を入れ直す。
2. アプリの「くわしい情報（おとな向け）」を開き、「検証用の記録を残す」に印が付いていることを確かめる。
3. 確かめたい撮り方を選ぶ（下の表の「撮り方」）。撮り方を変えるたびに一度ストップして、スタートし直す
   （スタートごとに記録が区切られ、どの撮り方の記録かが分かる）。

## 場面ごとの確かめ

それぞれ 10〜15 分ほど撮り、「結果」に書く。「残るべき」は保存されるべき、「残らないべき」は保存されるべきでない。

| # | 場面 | 撮り方 | スマホの置き方 | 期待 | 結果（残った写真の数・気づいたこと） |
|---|---|---|---|---|---|
| 1 | 誰もいない部屋（照明はそのまま） | おすすめ | 机に固定 | 残らないべき | |
| 2 | 誰もいない部屋で、照明をつけたり消したりする | へやの中で、近くの人 | 机に固定 | 残らないべき | |
| 3 | 部屋の中を人が歩いて横切る（2〜3 m） | へやの中で、近くの人 | 机に固定 | 毎回残るべき | |
| 4 | 部屋の中で人が座ったまま、少しだけ動く | おすすめ | 机に固定 | 残っても残らなくてもよい（多すぎないか見る） | |
| 5 | 外で、遠く（20 m 以上）を人が歩く | 外で、遠くの人 | 固定 | 残るべき | |
| 6 | 外で、木の葉が風で揺れるだけ（人はいない） | 外で、遠くの人 | 固定 | 残らないべき | |
| 7 | 体育館など、前の人や舞台を撮る（今回の写真の場面） | おすすめ | 手に持つ・ひざに置く | 舞台の人が動いたときに残るべき。自分の手・ひざ・となりの人だけの写真は残らないべき | |
| 8 | 歩きながら撮る | おすすめ | 手に持つ | 残る（歩きながらは全部残す決まり） | |
| 9 | 夜・暗い部屋で、人が横切る | おすすめ | 机に固定 | 残るべき（暗い所のざらつきだけでは残らないべき） | |
| 10 | 長い時間（1 時間以上）撮る | 長い時間 とる | 机に固定 | 本体が熱くなりすぎず、撮り続けられる | |

## 送るもの

1. 「くわしい情報（おとな向け）」の「記録を送る」で送った CSV（`ibc_log.csv`、あれば `ibc_log.1.csv` も）。
2. 上の表の「結果」。
3. 「残るべきなのに残らなかった」「残らないべきなのに残った」写真があれば、その時刻（写真の名前の日時）。

## 記録のまとめ方

```bash
python3 tools/dogfood/analyze_log.py ibc_log.1.csv ibc_log.csv > report.md
```

撮り方（セッション）ごとに、保存した回数と理由、あやしい保存（自分の手・となりの人など）、全画素・Ultra HDR で
つなげたか（つなげなかった理由）、変化の広さが静かな回と動いた回の間にあるか（勧める値）をまとめます。
